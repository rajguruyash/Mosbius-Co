RELEASES

Pick your release.

Mosbius & Co is published once for each platform. A macOS release is named like v1.1.0, and its Windows installer carries a fourth number, like v1.1.0.0. Each card below opens that release on GitHub, where the installer is.

Current: version 1.1.0, the Huddle release

v1.1.0

macOS · Apple silicon

23 November 2026

The Huddle release for Macs with Apple silicon: a small window that stays on top and keeps every agent within reach, notifications you can answer, a sound for each kind of event, and pause, resume, stop and restart from one place.

Open v1.1.0 on GitHub

v1.1.0.0

Windows · 64-bit

23 November 2026

The same Huddle release as a Windows installer, for 64-bit Windows. It is new and has not been tried on a real Windows computer yet. If Windows asks you to confirm before it runs the installer, choose More info, then Run anyway.

Open v1.1.0.0 on GitHub

Earlier: version 1.0.0, the first release

v1.0.0

macOS · Apple silicon

13 November 2026

The first public release, for Macs with Apple silicon: the pixel-art office, the coding agents on your machine found automatically, an Agent Manager in Settings, and a separate terminal for every agent. It comes from before the Huddle.

Open v1.0.0 on GitHub

v1.0.0.0

Windows · 64-bit

13 November 2026

The first Windows build, with the same features as v1.0.0, for 64-bit Windows. It was built but has not been tried on a real Windows computer. It comes from before the Huddle.

Open v1.0.0.0 on GitHub

Releases from before the Huddle do not have it. To get the current one, go to the download section, or see every release on GitHub, with the notes for each.
