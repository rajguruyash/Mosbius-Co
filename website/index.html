    WHAT IT DOES

    Your agents, one office.

    Mosbius & Co brings the coding agents you already use together, and gives you control over what they can reach.

    Finds your agents

    Claude Code, Codex and Gemini CLI are detected on your machine and keep the sign-in you already have.

    A terminal per agent

    Each agent has its own terminal, folder and history. Switch rooms whenever you like; your sessions keep running.

    Agent manager

    Hire, name and place agents, see what each is doing, and stop any of them from one window.

    Tools and services

    Run local tools on your computer or connect services like GitHub, Notion and Slack. Everything is off until you switch it on.

    Your own APIs

    Connect any REST API with its own key. The key stays encrypted and is never handed to the agent.

    Skills

    Browse a catalogue of skills, see where each comes from, install what you want and roll back any update.

      SKILLS

      Teach your agents new tricks.

      A skill is a folder of instructions an agent can load. Browse a catalogue, install what you like, and stay in control of every change.

      Discover and install

      Browse a community catalogue and install a skill for the agent you choose, with one click.

      Safe by default

      Installing a skill never connects a service and never grants permission. Anything that could switch something on is left out.

      Know where it came from

      Every skill keeps its source and exact version, and you can check at any time that it is unchanged.

      Update with a preview

      See every changed line before an update is applied, and roll back if you do not like it.

      Claude, Codex and Gemini

      Install the same skill for Claude Code or for Codex and Gemini CLI, and keep them separate.

      SECURITY AND PERMISSIONS

      You decide who can reach what.

      Agents start with no access. You switch things on, connect them, and choose exactly what each agent may do.

      You are in control

      Nothing is connected until you connect it, and nothing is reachable until you switch it on.

      Per-agent permissions

      Give each agent only the services it needs, and none by default.

      Read and write controls

      Choose read, write or a hand-picked list of tools. Sending, posting and deleting are always ticked by hand.

      Careful with credentials

      Keys and sign-ins are stored encrypted by your operating system and are not handed to the agent.

      Revoke any time

      Take access away and it applies at once. The Activity tab shows what was done.

      Local first

      Your workspace stays on your machine. There is no Mosbius & Co account.

      More detail in the security notes.
